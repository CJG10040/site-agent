의도 문서: [docs/intent/다음-기능.md](../docs/intent/다음-기능.md) · 할 일 목록: [tasks/todo.md](todo.md)

## 개요
앱을 첫 대지분석에서 끝나는 도구에서 **내 설계 과제를 끝까지 함께하는 도구**로 넓힌다. 순서는 **5 → 2 → 1 → 3 → 4**(사용자 결정)이고, 묶음 하나씩 끝내고 사용자 확인 → 커밋·배포한다. 각 묶음을 시작할 때 아래 '시작할 때 여쭐 것'을 먼저 묻는다(임의로 정하지 않음).

## 정한 것 (인터뷰·계획 중 사용자 결정)
- 3번 비율: 지도 틀은 **원·정사각 그대로**, 판 크기(mm)와 범례 자리(아래·오른쪽·빼기)로 전체 비율을 맞춤. 직사각 지도 틀은 나중 과제(도판 코드 60여 곳이 정사각 전제)
- 3번 패널 모드: 도판에서 **제목·출처·캡션·기준일 등을 모두 빼고 다이어그램만**
- 4번 조례 값: 국가법령정보센터 API는 우리 앱 브라우저에서 바로 부를 수 없음(2026-11-21 확인: 응답에 다른 사이트 허용 머리말 없음 — 공공데이터포털은 허용). 그래서 ① 4번 시작 때 공공데이터포털을 거치는 조례 API가 있는지 먼저 확인 → ② 없으면 **GitHub Actions가 정해진 때마다 법령센터 API로 조례를 받아 표(JSON)를 자동 갱신**. 이때 법령센터 키는 GitHub 저장소 '비밀 값'에 둠 — '키는 브라우저에만' 규칙의 예외로 사용자가 허용. 키는 사용자가 직접 넣음(대신 입력하지 않음)

## 구조 결정 (코드 조사 근거)
- **건물은 한 곳으로 흐른다**: 도판·환경 계산·3D 모형·DXF가 모두 `buildDiagramData()`(`src/diagrams/data.ts`)의 `buildings`를 씀 → 설계안 매스·지도에서 더한 건물은 여기서 끼워 넣으면 모든 곳에 들어감. 학생이 뺀 자료(`applyHides`)도 여기서 처리됨
- **대지 안 건물**: 환경 계산·3D 도판·여러 도판은 이미 `onSite` 건물을 뺌. 3D 모형 내보내기(`bldgSite` 레이어)·피겨-그라운드 등 남은 곳을 정리해 '처음부터 비움'으로 맞춤. 설계안 매스는 `onSite`와 다른 표시(예: `src: 'design'`)로 넣어 환경 계산에서 빠지지 않게
- **라이노 읽기**: 이미 쓰는 `rhino3dm` 8.35.0으로 읽음(새 패키지 없음). 단 rhino3dm.js에는 **Brep을 메시로 바꾸는 기능이 없음** → 메시·파일에 저장된 렌더 메시를 읽고, 없으면 '라이노에서 메시로 바꿔 저장' 안내. 돌출(Extrusion)은 직접 삼각형으로 바꾸는 길도 확인
- **매스 → 2.5D**: 환경 계산(그림자·일조·하늘·바람)은 '발자국 + 높이' 건물만 다룸 → 설계안 메시를 1m 안팎 칸의 높이 지도로 바꿔 높이 단계별 발자국 덩어리(층층이 쌓인 매스)로 만든다. 3D 도판·.3dm에는 원래 삼각형을 그대로. 필로티·캔틸레버 아래 빈 곳은 환경 계산에서 꽉 찬 것으로 봄(한계로 캡션에)
- **안(案)**: 프로젝트에 '현황(빈 대지) · A안 · B안 …'을 두고, 고른 안으로 도판·계산을 다시 함. 환경 계산 결과는 안마다 따로 저장
- **3D 도판 자르기**: 지금 `view3d.ts`는 건물 **가운데 점**이 틀 안이면 통째로 그림 → 발자국을 틀 모양(원·사각)으로 잘라 내고, 잘린 경계의 벽은 '잘린 면' 색으로
- **근거 목록**: 점 자료 `Pt`에 주소·링크 칸을 더하고(카카오 `place_url`·도로명주소, 상가 도로명주소 등 — 지금은 버리고 있음), 도판 결과(`PanelOutput`)에 '근거 점 목록'을 붙여 앱 화면 카드 아래에만 보여 줌(그림·내보내기에는 안 넣음). 빼기는 기존 '자료 빼기'(`HideEdit`)를 그대로 씀. 링크가 없는 자료는 카카오맵 좌표 링크(`map.kakao.com/link/map/이름,위도,경도`)로
- **패널 규칙**: 도판 글자 크기가 파일 13개에 60여 곳 박혀 있음(`font-size`) → 먼저 '글자·선 단계'를 한 곳으로 모으고(기본값에선 지금과 똑같이 나오게), 그 위에 규칙 화면을 얹음. 올린 글꼴은 이 브라우저 저장소에만, PNG는 글꼴을 SVG 안에 넣어 그리고, SVG는 글꼴 이름만(일러스트레이터는 컴퓨터에 깔린 글꼴로 엶)
- **자동 시험 없음**: 저장소에 시험 도구가 없음(새 패키지 안 들임) → 확인은 `npm run build` + 개발 서버에서 직접 보기 + 계산 함수는 임시 확인 스크립트. 글자 단계 정리(3번 첫 작업)는 52장 SVG를 고치기 전·후로 비교해 같은지 확인
- **확인용 자료**: 유스퀘어 내보내기 파일 사본(확인 뒤 지움, 사용자 원본·실제 사이트 프로젝트는 손대지 않음)
