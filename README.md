# 대지해석 에이전트 (Site Interpretation Agent)

건축학도생이 대지조사에서 모은 공공데이터와 현장 관찰을 **사실 · 관찰 · 해석 · 긴장 · 설계 질문 · 설계 가설**로 발전시키도록 돕는 웹 도구입니다.

- 사이트: https://cjg10040.github.io/site-agent/
- 개발 계획: [docs/개발계획서.md](docs/개발계획서.md) (v0.2: 도판·지형·이동·3D 단계 추가), 지형 가공: [docs/지형자료_가공계획서.md](docs/지형자료_가공계획서.md)
- 현재 단계: **종합 다이어그램 (Phase 12) + 수치지도 올리기** — ⑧ 해석·가설에서 긴장·기회·가설 카드를 지도에 놓고 화살표·영역·포인트·글상자로 그리는 종합 다이어그램(리포트·보드의 마지막 도판), ④ 공간정보에 국토지리정보원 1:5,000 수치지도 2.0 ZIP 올리기(측량 건물·층수, 도로경계·인도, 옹벽 단차를 넣은 대지 주변 2m 지형 → 도판·환경 계산·3D·DXF). 이전: **3D·DXF·보드 조판 (Phase 11 첫 판)** — ⑥ 도판에서 라이노 .3dm(10m 지형 면·등고선, 건물 돌출, 도로 면, 필지·공원·하천, 대지 중심 = 원점·실제 좌표 기록)과 DXF 평면 밑그림 내보내기, ⑨ 리포트의 보드(A4~A1·2~6열, 도판 순서·결론, PDF·PNG 300dpi). 이전: **계산형 환경 도판 (Phase 10) + 도판 개선** — 일조시간(동지·춘추분·하지, 대지가 다 보이는 주변 2m·반경 4m), 대지에서 본 하늘, 높이별 가시권, 단면도(남북·동서, 방향 돌리기), 도로 혼잡(거시)·대지 주변 차량 속도(미시), 상가 낮·밤 성격·대지 주변 vs 동네 업종, 생활 시설 아이콘 지도·생활권(5·10·15분), 실험: 바람 흐름(보행 높이)·여름 열쾌적(UTCI) → 도판 41장. 이전: **이동과 바람 (Phase 9)** — 바람장미(ASOS 매시 자료), 실시간 도로 속도(국가교통정보센터, 여러 장면 쌓기), 길의 연결(공간구문론 선택도 2장·도보권·가구), 가로 위요감(D/H) → 도판 32장. 이전: **지형 (Phase 8)** — 국토지리정보원 등고선 → 10m 지형 타일([site-agent-terrain](https://github.com/CJG10040/site-agent-terrain)), 지형 도판·사실 카드·지도 등고선. **도판 (Phase 7)** — 과제·첫 질문 → 대지 → 공간정보(15종) → 사실 카드 → **도판 22장(결론 한 문장·SVG/PNG)** → 현장 관찰 → 챗봇 왕복(해석·질문·가설) → 리포트(PDF)

## 사용 방법

1. 배포된 주소로 접속합니다.
2. **설정**에서 브이월드 인증키를 입력합니다. 키는 그 브라우저에만 저장되며 이 저장소에는 올라가지 않습니다.
3. 브이월드 마이페이지에서 인증키의 서비스 URL을 배포 주소로 등록합니다.
4. **연결 진단** 탭에서 지도·검색·주소·데이터 API가 정상인지 확인합니다.

## 개발

```bash
npm install
npm run dev      # 로컬 개발 서버
npm run build    # 타입 검사 + 빌드 (dist/)
```

`main` 브랜치에 올리면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다.

## 데이터 출처

- 브이월드 (국토교통부 공간정보 오픈플랫폼) — 지도, 검색, 주소, 연속지적도, 용도지역·지구, 건물통합정보, 도로망, 도시계획시설, 재해위험지구·하천망, 공공·문화·복지 시설, 통학구역, 주요상권·전통시장, 부동산 개방데이터(토지이용계획·토지특성·공시지가·토지이동)
- 통계청 SGIS 오픈API — 행정동·집계구 인구·가구·사업체 통계
- 공공데이터포털 — 국토교통부 건축HUB 건축물대장, 국토교통부(TAGO) 버스정류소, 기상청 ASOS 일자료, 소상공인시장진흥공단 상가(상권)정보 (서비스마다 활용신청 필요)
- 카카오 로컬 API — 주변 생활 시설 (카카오 디벨로퍼스 REST 키, '카카오맵' 사용 설정 필요)
- 국가교통정보센터(its.go.kr) — 교통소통정보 Open API, 표준노드링크 구간별 실시간 통행 속도 (오픈데이터 › 교통소통정보에서 인증키 신청)
- 공공데이터포털 기상청 ASOS **시간자료** — 바람장미, 여름 오후 기온·습도 (일자료와 별도로 활용신청)
- 국토지리정보원 1:5,000 수치지도 2.0 — 사용자가 국토정보플랫폼(map.ngii.go.kr)에서 받아 앱에 올리는 파일 (브라우저에만 저장)
- 삼각망 — [delaunator](https://github.com/mapbox/delaunator) 5.1.0 (ISC License, Mapbox)
- 라이노 .3dm 쓰기 — [rhino3dm](https://github.com/mcneel/rhino3dm) 8.35.0 (MIT License, Robert McNeel & Associates), 면 나누기 — [earcut](https://github.com/mapbox/earcut) 3.2.4 (ISC License, Mapbox)
- UTCI 계산식 — [jsthermalcomfort](https://github.com/FedericoTartarini/jsthermalcomfort) 1.4.0의 함수를 옮김 (MIT License, Federico Tartarini)
- 바로가기 — 카카오 로드뷰·지도, 네이버 지도, 토지이음, 국토정보플랫폼 과거 항공사진

각 키(브이월드·SGIS·공공데이터포털·카카오·국가교통정보센터)는 사이트의 **설정**에서 입력하며 브라우저에만 저장됩니다. **연결 진단**에서 키와 서비스별 활용신청 승인 여부를 확인할 수 있습니다.
지적·용도지역 정보는 참고용이며 법적 효력이 없습니다. 토지 소유 정보는 다루지 않습니다.
