# 대지해석 에이전트 (Site Interpretation Agent)

건축학도생이 대지조사에서 모은 공공데이터와 현장 관찰을 **사실 · 관찰 · 해석 · 긴장 · 설계 질문 · 설계 가설**로 발전시키도록 돕는 웹 도구입니다.

- 사이트: https://cjg10040.github.io/site-agent/
- 개발 계획: [docs/개발계획서.md](docs/개발계획서.md)
- 현재 단계: **Phase 0 — 기반 구축** (브이월드 지도·검색·연결 진단)

## 사용 방법

1. 배포된 주소로 접속합니다.
2. **설정**에서 브이월드 인증키를 입력합니다. 키는 그 브라우저에만 저장되며 이 저장소에는 올라가지 않습니다.
3. 브이월드 마이페이지에서 인증키의 서비스 URL을 배포 주소로 등록합니다.
4. **연결 진단** 탭에서 지도·검색·주소·데이터 API가 정상인지 확인합니다.

## 개발

```bash
npm install
npm run dev      # 로컬 개발 서버
npm run build    # 타입 검사 + 빌드 (dist/)
```

`main` 브랜치에 올리면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다.

## 데이터 출처

- 브이월드 (국토교통부 공간정보 오픈플랫폼) — 지도, 검색, 주소, 연속지적도, 용도지역

지적·용도지역 정보는 참고용이며 법적 효력이 없습니다.
