# 대지해석 에이전트 (Site Interpretation Agent)

건축학도생이 대지조사에서 모은 공공데이터와 현장 관찰을 **사실 · 관찰 · 해석 · 긴장 · 설계 질문 · 설계 가설**로 발전시키도록 돕는 웹 도구입니다.

- 사이트: https://cjg10040.github.io/site-agent/
- 개발 계획: [docs/개발계획서.md](docs/개발계획서.md)
- 현재 단계: **데이터 확장 (Phase 6)** — 과제·첫 질문 → 대지 → 공간정보(15종) → 사실 카드 → 현장 관찰 → 챗봇 왕복(해석·질문·가설) → 리포트(PDF)

## 사용 방법

1. 배포된 주소로 접속합니다.
2. **설정**에서 브이월드 인증키를 입력합니다. 키는 그 브라우저에만 저장되며 이 저장소에는 올라가지 않습니다.
3. 브이월드 마이페이지에서 인증키의 서비스 URL을 배포 주소로 등록합니다.
4. **연결 진단** 탭에서 지도·검색·주소·데이터 API가 정상인지 확인합니다.

## 개발

```bash
npm install
npm run dev      # 로컬 개발 서버
npm run build    # 타입 검사 + 빌드 (dist/)
```

`main` 브랜치에 올리면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다.

## 데이터 출처

- 브이월드 (국토교통부 공간정보 오픈플랫폼) — 지도, 검색, 주소, 연속지적도, 용도지역·지구, 건물통합정보, 도로망, 도시계획시설, 재해위험지구·하천망, 공공·문화·복지 시설, 통학구역, 주요상권·전통시장, 부동산 개방데이터(토지이용계획·토지특성·공시지가·토지이동)
- 통계청 SGIS 오픈API — 행정동·집계구 인구·가구·사업체 통계
- 공공데이터포털 — 국토교통부 건축HUB 건축물대장, 국토교통부(TAGO) 버스정류소, 기상청 ASOS 일자료, 소상공인시장진흥공단 상가(상권)정보 (서비스마다 활용신청 필요)
- 카카오 로컬 API — 주변 생활 시설 (카카오 디벨로퍼스 REST 키, '카카오맵' 사용 설정 필요)
- 바로가기 — 카카오 로드뷰·지도, 네이버 지도, 토지이음, 국토정보플랫폼 과거 항공사진

각 키(브이월드·SGIS·공공데이터포털·카카오)는 사이트의 **설정**에서 입력하며 브라우저에만 저장됩니다. **연결 진단**에서 키와 서비스별 활용신청 승인 여부를 확인할 수 있습니다.
지적·용도지역 정보는 참고용이며 법적 효력이 없습니다. 토지 소유 정보는 다루지 않습니다.
