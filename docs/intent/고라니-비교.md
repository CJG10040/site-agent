# 고라니(Gorani)와 비교 — 흡수할 것·버릴 것 (2026-11-22)

비교 대상: https://github.com/969flash/gorani-plugin (마지막 반영 2026-11-20, 0.4.0) · https://gorani.site/
읽은 것: PRODUCT.md, CLAUDE.md, docs/data_sources.md, docs/deliverables.md, docs/code_map.md, docs/research/08_building_height_reliability.md, docs/research/09_street_rail_detail.md, gorani.site 첫 화면.
**코드는 옮기지 않는다** — 저장소에 라이선스 표기가 없고(GitHub 감지 없음, Blender판 문서는 GPL 언급) 언어도 다르다(Python·Rhino). 방법·수치·코드표(공공 자료 사실)만 참고해 우리 식으로 새로 만든다.

## 1. 한 줄 비교

| | 고라니 | 우리(site-agent) |
|---|---|---|
| 형태 | Rhino·SketchUp·Blender·Archicad 플러그인(Python) + 소개 사이트 | 브라우저 웹앱(GitHub Pages), 서버 없음 |
| 목적 | 대상지 하나 → 3D 컨텍스트 모형 + 일러스트 베이스맵(.ai) + 현황도·분석도 22종 + 조서 CSV, '버튼 하나' | 대지해석 전 과정(질문·사실·도판 53장·관찰·해석·리포트·보드) + 3D 모형 + 법규 검토서 + 과거와 현재 |
| 수치지형도를 얻는 길 | **미리 만든 팩**: 브이월드 '수치지형도 1:5,000 **시군구 묶음**(dsId=30205)'·GIS건물통합정보 시도 전체본을 개발자가 받아 SQLite 팩으로 → **국내(춘천) 서버**에서 플러그인이 받음(하루 한도 문지기). 사용자는 SHP를 안 올림 | 학생이 국토정보플랫폼에서 **도엽 ZIP을 받아 올림**(1:5,000·1:1,000), 브라우저에서 바로 읽음 |
| 법적 처리 | 수치지형도 파생 팩은 국내 서버에만(공간정보관리법 제16조 국외 반출), 1:5,000 이상 등고선·표고는 웹 표시 금지·데스크톱 납품만, 1:1,000은 공공누리 4유형이라 팩에 안 넣음, 브이월드 API 응답은 저장 안 함(약관 제19조) | 학생 브라우저 안에서만 처리(저장소·서버에 안 올림) — 같은 원칙을 자연히 지킴 |

## 2. 우리 쪽이 이미 앞선 것 (그대로 둠)

- 1:1,000 수치지도 읽기(고라니는 라이선스 때문에 안 씀), 정밀도로지도(노면·보도 높이), 브라우저만으로 처리
- 교량·고가: 수치지도 교량(A007)·입체교차부(A009) + 표준노드링크 + 물을 건너는 도로 자동 다리, 상판·난간·교각(고라니도 비슷한 수준)
- 대지분석 흐름 전체(질문·사실 카드·관찰·해석·리포트·보드), 환경 계산(일조·하늘·바람·열쾌적·소음), 법규 검토서, 설계안 올려 비교, 과거와 현재, 패널 규칙

## 3. 흡수할 것 (우선순위)

| # | 무엇 | 고라니 방법 | 우리 지금 | 크기 |
|---|---|---|---|---|
| **1** | **철도** | 1:5,000 `A0150000` 철도(선로마다 한 줄, 구분 = 고속철도·보통철도·지하철(지상), 지하 구간 제외)·`A0171119` 철도중심선(단선·복선)·`A0191221` 승강장(면)·`A0201222` 승강장 지붕(면). 3D: 5 m 단면, 자갈 도상 사다리꼴·레일 두 줄(궤간 1,435 mm)·침목 0.6 m 간격, 승강장 = 레일면 + 1.135 m, 철교 위 구간은 상판 높이로 | **철도를 안 읽음** (도판·3D 모두 없음) | M |
| **2** | **교량 위 표고점 = 상판 높이** | 교량·입체교차부·인터체인지 면(+5 m) 안 표고점을 `spot_struct`로 따로 — **지형 삼각망에서 빼고** 상판 높이 실측값으로 씀(성동구 43곳 중 33곳에 있음, 성수대교 31 m). 없을 때만 끝점 경사 + 통과높이 추정 | 표고점을 모두 지형에 넣음 → **다리 밑 땅이 상판 높이로 솟을 수 있음**, 상판 높이는 정밀도로지도·경사로 추정 | S |
| **3** | **건물 높이 규칙** | ① 대장 건축면적 < 발자국 × 0.5 → 엉뚱한 대장이 붙은 것, 속성 불신(아파트 층수 오류의 72 %) ② 아파트·연립은 수치지형도 층수 ≥ 대장 층수 + 3이면 수치지형도 층수 ③ 층수→높이 = 용도별 a + b·층수(실측 2.3만 동: 단독 2.4+2.4n·공동 1.1+2.8n·1종근생 0+3.3n·2종근생 0.7+3.1n·업무 1.0+3.4n·교육 1.4+3.7n·종교 0+4.2n·결측 1.5+2.8n, 2.5n~8n로 자름) ④ 높이 출처 등급 A~D | 실측 높이 또는 층수 × 3.0(주거)·4.0(비주거)·5.0(공장)·3.3(모름) | S~M |
| **4** | **시군구 묶음 한 번에 올리기** | 브이월드 '수치지형도 1:5,000 시군구 묶음'(dsId=30205) zip 안의 도엽들을 씀 | 도엽 ZIP을 하나씩 받아 올림 | S |
| 5 | **현황도 더하기** | 토지이용현황도(필지 실제 이용, 2013 가이드라인 재분류) · 지목 현황도(28→16) · 공시지가 현황도(분위) · 향(aspect) 분석도 · 건축물 구조 현황도 · 국공유지 소유현황도 · 침수흔적·예상 · 필지·건축물 **조서 CSV** | 도판 53장에 이 여덟 가지는 없음(자료 일부는 이미 받음: 토지특성·공시지가) | 하나씩 S |
| 6 | 평평한 삼각형 보정 | 같은 높이 등고선끼리 이어 생긴 평평한 삼각형을 골짜기(낮춤)·꼭대기(올림)로 가려 점을 더하고 다시 삼각망 | 없음 — 2 m 격자 삼각망이라 골짜기 바닥·봉우리 꼭대기가 평평하게 잘림 | S |
| 7 | 출처·라이선스 문구 | 1:1,000 = 공공누리 4유형(변경·상업 금지), 1:5,000 등고선 웹 표시 금지 — 캡션·안내에 | 출처는 적지만 이 두 주의는 없음 | S |

## 4. 버릴 것 (가져오지 않음)

- **미리 만든 전국 팩 + 서버**: 우리는 국외(GitHub) 정적 사이트 — 수치지형도 파생물을 올리면 공간정보관리법 제16조(국외 반출)에 걸림, 서버를 두지 않는 원칙과도 맞지 않음. 대신 #4(시군구 묶음 올리기)로 수고를 줄임
- 서울 전용 자료(교통안전시설물 차선·횡단보도, 생활인구 250 m, 역사마스터, 비오톱) — 우리는 광주·전남·전북 중심
- Illustrator .ai(PostScript) 직접 쓰기 — 우리는 SVG(그룹 = 레이어)로 충분, 일러스트레이터가 그대로 엶
- 해외(OSM·PLATEAU 등)·회원·사용 통계·Archicad/SketchUp/Blender 굽기

## 5. 다음에 할 일 제안

1→2→3 순서(3D·도판의 정확도를 바로 올림), 4는 함께, 5는 고를 현황도부터. 시작할 때 여쭐 것: 철도를 도판(피겨-그라운드·도로 등) 어디에 그릴지, 3D 철도 디테일 수준(도상·레일·침목까지 / 선만), 건물 높이 등급을 도판·모형에 보일지, 더할 현황도.
