## 3 패널 규칙 — 묶음 D 시작 때 정한 것 (2026-11-21)
- **판 크기 = 지도 지름(mm)**: 모든 도판의 지도(원·정사각)가 같은 크기. 범례는 정한 자리(아래·오른쪽)에 필요한 만큼 붙어 바깥 길이는 도판마다 조금씩 다름
- **범례·방위표·축척은 각각 켜고 끄기**(규칙 전체 + 도판 하나만). 처음 값은 셋 다 켬(일러스트레이터에서 지우기가 새로 그리기보다 쉬움)
- **규칙은 패널 모드에만**: 보통 도판(⑥ 화면 기본, ⑨ 보드·리포트)은 늘 지금 모습 그대로
- **단위**: 글자 pt, 선 mm

## 4 법규 — 묶음 E 시작 때 정한 것 (2026-11-21)
- **자리**: 새 단계 **⑪ 법규 검토**(⑩ 3D 모형 다음) — 용도·규모 입력, 체크리스트, 건축 가능 영역이 한 화면. 가능 영역은 ⑥ 3D 도판·⑩ .3dm에도
- **조례 지역**: 첫 판부터 **광주 + 전남·전북 모든 시·군**(약 37곳). 못 읽은 값은 '확인 필요' + 원문 링크
- **주용도 목록**: 건축법 시행령 별표 1의 **큰 분류 + 법 기준이 갈리는 자주 쓰는 세부 용도**
