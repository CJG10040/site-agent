## 0. 한눈에

건축학과 학생이 대지조사에서 모은 **공공데이터와 현장 관찰**을 **사실 → 관찰 → 해석 → 긴장·기회 → 설계 질문 → 설계 가설**로 발전시키도록 돕는 웹 도구입니다. 같은 자료로 **도판 52장**, **리포트·보드**, **라이노 3D 모형(렌더링용·콘타 모형용)**까지 만듭니다.

| 원칙 | 내용 |
|---|---|
| 사용자 | 학생 본인 1인 (로그인·회원 없음) |

## 1. 앱 틀 (모든 화면 공통)

- **홈**: '내 프로젝트' 목록(대지·마지막 내보내기 표시), 새 프로젝트, 프로젝트 파일 가져오기
- **위 막대**: 프로젝트 이름, 저장 상태(저장 중… / 브라우저에 저장됨 / 저장 실패), **버전 저장**, **내보내기**(프로젝트 파일), **연결 진단**, **설정**, **테마**(자동·밝게·어둡게)
- **왼쪽 단계 목차**: ① 과제 ② 첫 질문 ③ 대지 ④ 공간정보 ⑤ 사실 카드 ⑥ 도판 ⑦ 현장 관찰 ⑧ 해석·가설 ⑨ 리포트 / '모형 만들기' 묶음 ⑩ 3D 모형. 단계마다 진행 표시(예: '확인 4', '가설 0 · 질문 0'). **목차 접기**(번호만 남겨 작업 공간을 넓힘, 이 브라우저에 기억)
- **설정**: 키 입력(보기·숨기기) — 브이월드 인증키(+ 서비스 URL 안내·domain 직접 지정), 통계청 SGIS(서비스ID·보안키), 공공데이터포털 일반 인증키, 카카오 REST 키, 국가교통정보센터 Open API 키
- **연결 진단**: 키마다 실제로 불러 보고 결과(응답 정상·오류 사유·걸린 시간)와 고치는 법 — 브이월드 지도·검색·주소·데이터, SGIS, 공공데이터포털(건축HUB·TAGO·ASOS 일·시간·상가), 카카오, 국가교통정보센터
- **버전 저장**: 지금의 해석(카드·도판 결론·요약문·첫 질문·과제·종합 다이어그램)을 이름 붙여 저장. 다시 수집 직전·리포트 인쇄 뒤·피드백 받을 때 자동 저장(바로 앞과 같으면 건너뜀, 자동은 최근 20개)
- **프로젝트 파일**: JSON 하나(사진은 base64로 안에, 버전 함께). 가져오기는 새 프로젝트 또는 사본으로, 다른 기기의 현장 관찰만 합치기도 가능

## 2. 단계별 화면과 기능

### ① 과제
프로젝트 이름 · 과제명 또는 공모전 주제 · 건축 프로그램 · 예상 규모·연면적 · 사용자·대상자 · 설계 대상의 성격 · 제출 결과물 형태 · 이미 가지고 있는 자료 · 현장답사(다녀왔음 / 갈 예정 / 계획 없음). 모든 챗봇 명령어의 '과제 맥락'이 됩니다.

### ② 첫 질문 (데이터를 모으기 전에)
- 이 대지를 통해 가장 궁금한 것
- 관심 관점(여러 개): 이 장소의 사람과 관계 · 장소의 기억과 역사 · 도시의 이동과 경계 · 생태·기후·물의 흐름 · 빈 공간과 유휴공간 · 지역의 생산·상업 활동 · 주거와 생활 방식 · 앞으로의 변화 · 아직 모르겠음 + 직접 적기
- 이 대지를 고른 이유·기억에 남은 장면·불편했던 점
- 피하고 싶은 일반적인 해석(예: '연결'·'소통'·'지속가능성'으로만 끝나는 개념)

### ③ 대지
- 주소·장소 검색(브이월드), 지도(일반·항공사진·회색·야간)
- **경계 지정**: 필지 누르기로 고르기(경계에 걸친 필지 찾기, 필지 합계 면적·지목) 또는 직접 그리기·고치기
- 태양 궤적 겹쳐 보기
- **주변 조사 반경**: 슬라이더 250m~3km(50m 단위, 눈금 250m·500m·1km·2km·3km가 고르게 놓인 비례 간격, 눈금 누르기·키보드 ←→), '걸어서 약 n분', 1km 넘으면 느려진다는 안내

### ④ 공간정보
- **수집할 자료** 19묶음을 골라 한 번에 수집(키가 없는 묶음은 표시) — 목록은 [3.1](#31-수집-자료-19묶음)
- **수집 진행도**: 진행 막대(끝난 항목/전체·%)·지난 초·지금 받는 항목(예: 'GIS건물통합정보 12,000건 받는 중, 범위를 9칸으로 나눠 3번째'), 수집 뒤 '자료 정리·사실 카드' → '환경 계산' 단계 표시
- **수집 결과**: 묶음별 항목마다 완료(건수)·해당 없음·오류(사유)
- **지도**: 바탕 4가지 + 겹쳐 보기(하천·재해·방재·공공·복지·상권·전통시장·버스정류소·상가(업종 색)·생활 시설 등), 건물·도로·집계구 통계·등고선·태양 궤적 켜고 끄기, 누르면 정보
- **수치지도·정밀도로지도 올리기**: 국토정보플랫폼에서 받은 1:5,000 수치지도 2.0 ZIP, 1:1,000 수치지도 2.0(NGI·NDA), 정밀도로지도 ZIP을 끌어다 놓기. 반경에 걸치는 도엽 번호 안내(올린 것 ✓), 반경 안만 저장, 읽기 방식이 바뀌면 '다시 올리기' 안내
- **항목별로 쓸 자료**: 지형·건물·도로(도로경계·인도·도로중심선·횡단보도·교통섬·교량·고가차도)·가로 시설(정류장·가로수·가로등·담장)·하천마다 1:1,000 / 1:5,000 / 정밀도로지도 / 브이월드 / 안 씀. 2020년(1:1,000)과 2025년(1:5,000) 사이 **바뀐 곳**(건물이 생기거나 없어진 곳, 땅이 2m 넘게 달라진 곳)은 자동으로 새 자료로 바꿔 넣고 지도로 보여 줌
- **바로가기**: 카카오맵 로드뷰·위치, 네이버 지도, 국토정보플랫폼(과거 항공사진), 토지이음(PNU)

### ⑤ 사실 카드
- 수집하면 **사실 카드가 자동으로** 만들어지고 **처음부터 확인됨**. 출처를 열어 보고 틀리거나 중요하지 않은 것은 **제외**, 어색하면 **수정**, **메모**. '사람 확인 필요' 표시가 붙은 카드는 특히 출처 확인
- 카드: 번호(F-01…)·종류(사실/미확인)·주제별 묶음·신뢰도·출처 칩(출처 상세: 기관·자료·수집일·갱신일·범위·좌표계·한계·원본 요청 주소)·현장 관찰 연결(일치/다름)
- 요약: 확인된 사실 수(5개 이상 권장)·제외한 사실·미확인(추가조사 필요)
- **사실 직접 추가**: 문헌·통계·도면 등 — 사실·주제·출처 이름(필수)·링크·자료 기준일·한계
- **정성 조사 (챗봇)** — 맨 위 칸
  - '조사 명령어 만들기·복사' → 웹 검색이 되는 챗봇에 붙여 넣기
  - 주제: 최근 3년의 **이슈·갈등·개발 계획**, 기간 제한 없는 **역사·장소의 기억**, **지역 문화·생활**
  - 스케일 5단계마다 주요 이슈: **대한민국 → 광역 → 시·군·구 → 동 → 대지 주변(조사 반경)**
  - 원칙: 웹 검색으로 확인한 것만, 항목마다 출처·주소(URL)·시점, 해석·평가 안 함, 소유자 등 개인 정보 조사 금지, 검색 못 하면 '검색 불가'
  - 답 붙여 넣기 → 읽기(형식이 조금 흐트러져도 읽음, 못 읽은 항목은 이유) → '카드로 넣기' → 출처가 붙은 사실 카드(확인됨, 같은 항목은 다시 넣지 않음, URL 없으면 신뢰 낮음). 카드에 스케일·시점·출처·'출처 열기'

### ⑥ 도판
- **대지 개요 카드**: 대지 면적·용도지역·건폐율·용적률 상한과 최대 건축면적·연면적·공시지가 / 반경 안 건물 수·평균 층수·평균 사용승인 연도·30년 넘은 비율·가장 많은 용도·가까운 역·정류소 수·높낮이 차
- **도판 52장** (목록은 [4.2](#42-도판-52장)) — 카드마다 그림·요약 수치·출처와 한계 캡션, **결론 한 문장** 칸, '리포트에 넣기', SVG·PNG, 평면/3D(지도 도판)
- **설정**(바꿔도 바로 다시 그리지 않고 초안으로 모았다가 **'도판 생성'**을 누르면 바뀐 도판만 다시 그림, 진행도): 틀(원형·사각형) · 바탕(종이색 칠함·투명) · 대지 표시(경계선·채움·점) · 고층/저층 기준 · 그림자·일조 날짜(동지·춘추분·하지)와 시각 · 단면 방향(15° 간격)·높이(실제 비율·×2·×4)·범위(대지와 주변·반경 전체) · 바람장미 계절 · 도로 속도 장면 · 계산·지형 칠하기(매끄럽게·칸 그대로) · 바람 실험(흐름선·화살표) · 지형 음영(켬·끔) · 3D 보는 방향(8방위)·기울기(30·45·60°)·높이(×1~3) · PNG 크기
- **도판 색**: 묶음 16개(기본·색약 친화·흑백(인쇄) / 종이·세이지·종이·남색 / 파스텔·봄·하늘·민트 / 콘크리트·벽돌·목재·금속 / 밤(검정)·진남색 / 빨강·남색·청록·주황) + **테마색 + 포인트색**(추천 짝 12개 또는 두 색을 직접 고름 + 밝게·파스텔·어둡게, §6.6) + **색 직접 고치기**(바탕·글자·바탕 건물·미상·물·녹지·대지 강조·단계색 5·범주색 8·양쪽 단계색 5) + 도판 하나만 다른 색
- **도판 고치기**(도판을 크게 열기): 보기 · **자료 빼기**(누른 곳의 정류소·역·상가·시설·건물·공원 등을 이유와 함께 빼면 모든 도판·개요·3D·DXF·환경 계산에서 빠지고 다시 수집해도 유지) · **표기 옮기기**(글자 끌기·숨기기). '학생이 고친 것' 기록·되돌리기, 캡션·리포트에 표시
- **겹쳐 보기 1~3**: 아래·위 도판 고르기, 위 도판 면 그대로/선만·진하기, 자주 쓰는 짝 5개
- **분해 다이어그램**: 기본 6층(지형 → 녹지·하천 → 도로 위계 → 대중교통 → 건물 → 대지)을 띄워 쌓기, 층 더하기·빼기·순서·보는 방향
- **도판 결론 챗봇 왕복**: 도판별 수치·한계·학생이 쓴 결론을 넣은 명령어 → 답(`### [도판] id` / `결론1:`)에서 도판마다 후보 2개 → 눌러 고르거나 고침
- 받기: 낱장 SVG(일러스트레이터에서 레이어로 열리게 그룹 이름)·PNG(2000~6000px), 전체 ZIP
- 3D·CAD 내보내기는 ⑩으로 안내

- 사실 카드와 잇기: **일치 / 현장과 다름 / 자료에 없던 새로운 발견** — 세 묶음으로 보기, 시간대·위치 필터
- 다른 기기(휴대폰)에서 적은 관찰을 프로젝트 파일로 합치기

### ⑧ 해석·가설
탭 6개와 위의 진행 표시(MVP 기준: 관계·긴장·기회·해석·질문·가설 개수)
- **챗봇 왕복**: 단계 ①~⑤(아래 표) 고르기 → 준비 상태 경고 → 명령어 복사(길면 '1/3·2/3·3/3'로 나눠 복사, 앞 조각엔 '받음'이라고만 답하라는 지시) · 관찰 사진 묶음 이미지(관찰 번호와 함께 3×3 한 장, 챗봇에 첨부용) → 답 붙여 넣기 → 미리보기(형식 밖 글은 '분류되지 않은 답변', 없는 근거 번호는 '근거 확인 필요') → 카드로 넣기. 왕복 기록 저장

  | 단계 | 요청 | 만드는 카드 |
  |---|---|---|
  | ① 관계·긴장·기회 | 사실·관찰 사이 관계(공간적 인접·거리와 접근·밀도와 분포·시간적 변화·충돌·반복·단절·공존·배제·보존과 변환) 5+, 긴장 3+, 기회 2+ | 해석(관계)·긴장·기회·미확인 |
  | ② 복수 해석·설계 질문 | 긴장·기회마다 현실적·관계적·반전적 해석 3개(반전 질문), 설계 질문 3+(보존·드러냄·연결·분리·공유·비움·변화 / 스케일 6단계) | 해석·질문·미확인 |
  | ③ 설계 가설 | 서로 다른 가설 3+ (근거·해석·해결하려는 긴장·공간적 행동(공간 동사)·예상 경험·장점·위험·추가 조사·스케일) | 가설·미확인 |
  | ④ 심화·반대 해석 (선택) | '발전시키기' 카드의 변형, '반대 해석 만들기' 카드의 반대 해석 | 가설·해석·질문 |
  | ⑤ 추가 조사·패널 요약 (선택) | 추가 현장조사 5+(언제·어디서·무엇을·어떻게), 패널용 대지해석 요약문 400자 | 미확인·요약 |

  모든 명령어에 들어가는 것: 역할, 과제 맥락·첫 질문·대지, **확인된 사실(F-)·현장 관찰(O-)·자료와 현장 비교·도판 결론·미확인(U-)**, 앞 단계 카드(반응·메모 포함), 받은 피드백, 원칙 9가지(설계를 대신 결정하지 않기, 없는 사실·수치 만들지 않기, 근거 번호만 쓰기, 인구 통계로 행동 단정하지 않기, 자료와 현장이 다른 곳은 질문으로, 법규는 '확인 필요', 추상어 대신 공간 동사, 수상작 흉내 금지, 단정 대신 가능성 표현), 답 형식(`### [유형] N번호` + `항목명: 내용`)
- **카드 보드**: 사실 → 관계 → 긴장·기회 → 해석 → 질문 → 가설 흐름도, 카드를 누르면 상세(필드·근거·반응·메모·이력·받은 피드백)
- **반응**(카드마다): 동의 · 부분 동의 · 현장과 다름 · 중요하지 않음 · 더 조사하기 · 반대 해석 만들기 · 발전시키기 / 직접 수정 / 지우기
- **긴장·기회**: 설계 방향(보존할 것·드러낼 것·피할 것·변환할 것·방향 미정)별 묶음
- **가설 비교**: 가설을 열로 놓고 근거·해석·긴장·공간적 행동·예상 경험·장점·위험·추가 조사·스케일·반응을 나란히
- **종합 다이어그램**: 지도 위에 기호를 그리고 카드를 놓는 해석 도판
  - 기호 20가지 — 흐름(화살표·차량 흐름·보행 흐름·바람·소음·시선·조망) / 선(경계·단절·활성 가로면·축·완충대·선) / 점(입구·랜드마크·결절점·긴장 지점·중요한 곳·점) / 면(영역·버블·보존·불가 구역) / 글상자·카드 배지
  - 굵기 3단·선 모양·폭·양방향, 색 = 설계 방향(먹색 = 방향 없는 조건)
  - 바탕: 회색 건물·도로 또는 도판 하나(연하게), 반경 150m~수집 반경
  - **기호마다 근거**(카드·도판) 잇기, 근거 없는 기호 표시
  - 완성 도판은 ⑥ 마지막 번호·리포트·보드에 자동으로 (캡션 '학생이 그린 해석이며 사실이 아님')
- **피드백**: 받은 날·누가(교수·조교·동료·외부 전문가·기타)·자리·내용·관련 카드·도판, 번호 FB-01…, 반영 상태(아직·반영함·보류·다르게 판단)와 반영 내용. 적을 때 그 시점 버전 자동 저장 → '받은 뒤 바뀐 것'. 카드 상세·도판 카드·리포트·챗봇 명령어에 이어짐
- **패널용 대지해석 요약문**: ⑤ 단계 답에서 가져와 직접 고침 → 리포트

### ⑨ 리포트
보기 3가지
- **리포트**(인쇄·PDF): 표지 → 대지해석 요약 → 첫 질문과 관점 → 대지의 사실 → 도판('리포트에 넣기'한 것 + 결론, 종합 다이어그램 기호와 근거 표) → 현장 관찰(사진) → 관계 분석 → 대지의 긴장과 기회 → 서로 다른 해석 → 설계 질문 → 설계 가설 비교 → 추가로 확인할 것 → 받은 피드백과 반영 → 출처와 한계 → 해석 과정 기록(조사 버전·학생이 고친 것). '학생이 확인·동의한 카드만' 거르기, 근거 번호 표시
- **보드 (도판 조판)**: 용지 A4~A1·가로/세로·2~6열, 제목·대지 개요·도판별 결론 켜고 끄기, 도판 순서 바꾸기 → 인쇄(PDF)·PNG 300dpi·SVG. 한 쪽에 안 들어가면 다음 쪽
- **변화 기록**: 버전 목록(이름 바꾸기·지우기), 두 시점 비교(카드 생김·빠짐·바뀜, 종류별 수, 첫 질문, 도판 결론, 요약문, 종합 다이어그램 나란히, 피드백 변화)

### ⑩ 3D 모형
- **모형에 쓰는 자료**: 무엇이 들어가는지(지형·건물·도로·디테일 출처), 수치지도·정밀도로지도 올리기 칸
- **지붕 모양**: 반경(50·100·200·300m) 안 건물의 건축물대장 지붕 구조를 받아 저장(콘크리트 → 평지붕 + 파라펫, 기와·슬레이트 → 박공, 판넬·강판 → 낮은 경사), 반경 밖·대장 없음은 규칙(1~2층 단독주택 박공, 나머지 평지붕)
- **나무**: 반경 안 그루 수(출처별), 넓은 길 가로수·공원 격자 켜고 끄기·간격, 자치구 수종 비율과 출처, 항공사진 지도에서 **심기·지우기·줄로 심기**(수종 고르기, 되돌리기)
- **작업대** (탭 2개)
  - **렌더링 모델**: 범위(**반경 슬라이더**, 대지가 다 들어가는 값 ~ 조사 반경, '가로·세로 n km' 함께, 1km 넘으면 안내) · 디테일 단계(가벼움·보통·자세히) · 항목 29개 켜고 끄기 · **어림 치수 59개**([3.7](#37-모형-어림-치수-59개)) · 들어가는 것 표·물체 수·예상 파일 크기·경고 · 렌더 재질(사실적 + 무늬 / 사실적 단색 / 흰 모형 / 재질 없음) · 지형에 항공사진 입히기(키 필요) · 엔스케이프·D5 쓰는 법 · **3D 미리보기**(돌리기·확대·옮기기, 남서·남동·북쪽·위) · 내려받기: **라이노 .3dm**(진행 막대·%·지난 초, 화면이 멈추지 않게 따로 계산) · 무늬 이미지 ZIP · DXF(평면 밑그림)
  - **콘타 모형**: 축척(1:200·300·500·1000·2000·직접) · 판 두께(1·2·3·5mm·직접, 등고 간격 = 두께 × 축척) · 모형 크기(한 변 mm) · 재료 판(기본 600×900mm) · 도로 처리(새김선·따로 자른 조각·파내기) → 판 수·조각·재료 판 장수, 3D 조립 미리보기, 레이저 판 도면, 라이노 .3dm(mm). 하천이 있으면 '렌더링 모델 탭의 어림 치수에서 고침' 안내

### 3.5 계산 규칙 (요약)
- **건물 높이**(도판·환경 계산): 실측 높이(층당 2.2~8m로 어울릴 때) → 없으면 층수 × 용도별 층고(주거 3m·비주거 4m·공장·창고 5m·용도 모름 3.3m) → 층수도 모르면 3m. 지하만 있는 시설(지하상가·역)은 뺌. 3D 모형은 어림 치수의 층고를 씀
- **길의 연결**: 도로중심선을 교차점에서 나눈 보행망, 공간구문론 **각도 선택도**(Brandes, 정규화 NACH, 출발 6,000개 넘으면 표본), 도보권 = 대지 경계 30m 안 길에서 길 따라 잰 거리(분당 80m), 가구 = 평면 그래프의 면, 가로 위요감 D/H = 길 가운데 10m마다 양옆 첫 건물
- **환경 계산**(Web Worker, 결과 압축 저장): 일조시간 = 10분마다 건물 그림자(볼록 껍질) + 지형 지평선 각, 대지 주변 2m·반경 전체 4m 칸, 동지 09~15시 연속 2시간·08~16시 4시간 경계(판정용 아님) / 하늘 = 16방위 300m 올려본각(SVF), 대지 하늘 그림은 360방위 / 가시권 = 칸마다 '이 칸에서 보이려면 대지에 몇 m 이상' / 바람(실험) = 바람장미 계절별 주풍으로 보행 높이 평면 격자 볼츠만(D2Q9, 20m 이상만 막고 낮은 건물은 다공성), 범위 250~800m / 열쾌적(실험) = 더운 여름 오후(최근 3년 7~8월 14~16시 상위 10%) 기온·습도 + 바람 비 + 평균복사온도 → UTCI(jsthermalcomfort 공식)
- **교통소음(실험)**: 도로 폭별 낮 기준 소음을 선 음원 거리 감쇠, 건물에 가리면 −8dB, 배경 45dB, 환경기준 낮 65dB와 비교
- **경사도·물길**: 50m 평활 경사 5구간, 지형으로 빗물 흐름(웅덩이 채움 → 8방향 → 흐름 누적, 집수 1ha 이상), 고일 수 있는 곳
- **법규 개요**: 용도지역 → 국토계획법 시행령 제84·85조 건폐율·용적률 법 상한, 최대 건축면적·연면적, 건축법 시행령 제86조 정북 일조(주거지역). '조례·지구단위계획으로 더 낮을 수 있음' 경고
- **상가**: 업종 12묶음, 낮·종일·밤 성격, 대지 경계 100m 안 vs 반경 전체 비교(×배, '대지 주변엔 없음'), 건물마다 가장 많은 업종 색
- **생활 시설**: 12분류 6묶음(교통·교육·의료·장보기·문화·공공), 가장 가까운 곳까지 걸어서 n분(길의 연결이 있으면 길 따라)
- **도로 속도**: 거시 = 실제 ÷ 제한속도(30% 미만 정체), 미시 = 안전속도 5030 기준 20·30·40·50km 구간

### 3.6 3D 모형 만들기 (렌더링 모델)
- 좌표: **대지 중심 = 원점**(EPSG:5179 미터, x 동·y 북), 높이 0 = 대지 중심 지면. 파일에 지구 위치(경위도·해발·진북)·EPSG:5179·5186 좌표 기록
- 지형 면: 위 격자의 삼각형 메시, 등고선·계곡선(같은 보간이라 정확히 겹침)
- **땅 다듬기**(모형 지형 사본만, 도판·환경 계산 지형은 그대로): 도로 면 안을 약 18m로 매끈하게 + 밖 4m 서서히 이음(정밀도로지도 노면 실측 높이를 6배 무게 기준점으로) / 물 = 가까운 물가 땅으로 고른 평평한 물 높이(+ 하천 깊이 강조), 물 밑 파기, 둔치 비탈
- 건물: 바닥 = 발자국 아래 가장 낮은 지면, 높이 = 실측 또는 층수 × 층고, 중정까지 돌출. 지붕 모양(평지붕 + 파라펫 / 박공 / 낮은 경사)
- 도로·인도·교통섬·연석·차선(15cm 면, 겹선·점선)·노면표시(실제 화살표 모양, 진행 방향은 주행경로링크·우측통행 규칙)·횡단보도 줄무늬·안전지대 빗금·어린이보호구역 적색 포장
- 하천: 물 면(평평) / 둔치(잔디, 물 아래) — 같은 하천을 여러 자료가 겹쳐 그리지 않게 정리
- 다리·고가: 수치지도 교량·입체교차부 → 없으면 브이월드 표준노드링크 교량·고가차도 → 없으면 도로가 물을 건너는 곳. 상판 높이 = 상판 위 노면 실측 + 이어지는 도로 높이(거리 반비례) + 물 위 여유, 고가는 가지 끝에서 길을 따라 경사, 교각(20m 넘는 다리는 늘)·난간
- 나무: 1:1,000 가로수·정원수 + 넓은 길(폭 15m 이상) 규칙 가로수 + 공원 격자 + 직접 심은 것, 수종은 광주 자치구별 가로수 비율, 원뿔형·넓은형·둥근형 **라이노 블록**
- 가로 시설: 정류장 쉘터(지붕·유리·의자·표지)·가로등(기둥·팔·등)·신호등·지주·교통안전표지 판(주의·규제·지시·보조 모양)·방호시설·과속방지턱·담장·가드레일
- .3dm: 한글 레이어(단계·항목에 따라), 물체 이름·사용자 문자(층수·용도·높이·수종·지붕 등), 문서 정보(원점·자료·어림 방법·고친 어림 치수), 렌더 재질(SA_ 이름, PBR + 무늬 이미지 파일 안에, 메시마다 실제 크기 UV, 항공사진 SA_Aerial)
- DXF(AutoCAD R12): 영문 레이어(한글 깨짐 방지), 등고선 높이, 층수·지번 글자, 평면 밑그림
- 라이노 모듈(rhino3dm wasm)은 내려받을 때만, 작업자 스레드에서 불러 화면이 멈추지 않음. 메모리를 넘으면 '범위·단계·재질을 낮춰 다시' 안내

### 6.6 도판 디자인 (2026-11-20 새 디자인 2차)
도판은 SVG를 코드로 그리며 색은 **도판 색 묶음**(`diagrams/palette.ts`·`themePalette.ts`)을 씀 — UI 토큰과 따로 움직임. 도판 엔진(틀·범례·방위표·축척·캡션)은 `diagrams/compose.ts`·`frame.ts`·`render.ts`.

- **틀·글자**(사용자 결정: 틀 모양은 그대로, 글자만 정리): 원·사각 틀, 방위표, 축척 막대, 범례 3열 배치는 그대로. 모든 도판·보드·틀 없는 도판(단면·바람장미·하늘·스케일별 이슈·생활권 등)·종합 다이어그램의 굵기 700 → **600**, 범례 견본은 **각진 네모**(가는 먹 테두리). 보드 머리 글자색은 앱과 같은 먹(#18181b)·보조(#5f5f66), 결론 막대는 레드라인(#d42a1e). 종합 다이어그램의 카드 배지는 알약 대신 앱의 근거 번호처럼 **흰 바탕 + 종류 색 테두리·글자**의 각진 표
- 도판 글꼴은 Pretendard 그대로(SVG를 그림으로 바꿀 때는 컴퓨터에 깔린 글꼴로 그려지므로, 인터넷 글꼴인 IBM Plex Mono는 도판에 쓰지 않음)
- **색 묶음 16개**: 이름·묶음·성격은 그대로, 조합을 공개 자료로 다듬음 — ColorBrewer(colorbrewer2.org, 단계·양쪽 단계), Paul Tol 색 안내서(색약에도 구분되는 범주색), CARTOColors(지도용 단계·범주색, 어두운 지도용 '밝을수록 강함' 단계), Okabe–Ito(색약 친화). 묶음마다 `palette.ts`에 '참고:'로 적음
  - '기본'(사용자 결정): 중립 회색 바탕 건물 + 남청 단계색 + 또렷한 범주색 + 레드라인 대지 (예전 베이지·적갈색 느낌은 종이톤·재료 묶음이 맡음)
  - 재료 묶음은 재료 색을 바탕·단계색에, 대지는 재료의 반대색(콘크리트 = 공사 안전 주황, 벽돌·목재 = 청록, 금속 = 코르텐·구리)
- **검증 기준**(dataviz 검증 스크립트 + OKLab 계산, 지도 채움에 맞춤): 범주색 이웃 칸이 보통 눈 ΔE ≥ 15, 적·녹 색약 시뮬레이션(Machado 2009) ΔE ≥ 6(범례가 늘 함께 있음) / 단계색은 밝기가 한 방향으로 고르게, 가장 옅은 칸도 종이(ΔE ≥ 5)·바탕 건물(ΔE ≥ 4)과 구분 / 양쪽 단계색 가운데는 무채색 / 대지 강조색은 종이 위 대비 3:1 이상, 단계색과 뚜렷이 다름 / 보조 글자 대비 4.5:1 이상. 16개 모두 통과
- **범주색 칸의 뜻은 고정**: 0 노랑(낮) · 1 주황 · 2 빨강·장미 · 3 파랑 · 4 청록 · 5 보라(밤) · 6 회색(기타) · 7 갈색 — 도판들이 칸 번호에 뜻을 걸어 둠(낮·밤 상권, 현장과 다름·새 발견 등). 이웃 칸은 밝기를 번갈아 둬 구분을 도움
- **테마색 + 포인트색**(사용자 결정: 추천 짝 + 직접 고르기): 테마색 = 단계색(옅음 → 진함)과 바탕·글자의 옅은 기운, 포인트색 = 대지 강조 + 양쪽 단계색의 뜨거운 쪽(더위·빠름). 범주색은 칸 뜻을 지키며 두 색 쪽으로 조금 기울이고, 가장 가까운 칸에 두 색을 그대로 넣은 뒤 이웃 칸 구분이 기준을 넘도록 밝기를 조정. 추천 짝 12개(먹 + 레드라인 · 남색 + 주황 · 청록 + 산호 · 세이지 + 테라코타 · 슬레이트 + 머스터드 · 숲 + 금빛 · 와인 + 민트 · 올리브 + 버밀리언 · 라벤더 + 올리브 · 모래 + 남청 · 회청 + 분홍 · 갈색 + 하늘)는 밝게·파스텔·어둡게 36가지 모두 위 검증 통과. 예전 방식(포인트색 없이 유사색·보색·세 색)으로 저장된 보드는 그대로 보이고, 고르면 새 방식으로 바뀜

## 8. 남은 일과 알려진 한계

- **예상 파일 크기**: 반경 1km 넘는 3D 모형에서 실제보다 작게 어림(다시 맞추기)
- **넓은 반경**: 반경 3km 수집은 실제 키로 아직 확인 못 함(칸 나누기는 계산으로 확인). 3D 범위를 넓히면 미리보기가 10초 넘게 걸리고 그동안 화면이 멈춤. 수집 뒤 자료 정리 단계도 몇 초 멈출 수 있음
- **다리·하천**: 하천 바닥 높이·교각·고가 진입로는 어림. 하천 옆 진입 램프는 평평
- **콘타 모형**: 아래 판을 테두리만 남기기, 모양대로 맞춰 넣는 배치, 직사각형 모형, 하천·공원 새김
- **종합 다이어그램**: 계획했지만 아직 안 한 것 — 분석 결과 후보 넣기, 주장 한 문장 + 핵심 발견, 손그림 스위치
- **그 밖에 아직 안 한 것**: 과거 항공사진 비교(공개 API 없음), 두 대지 비교, 관계선 직접 그리기, 실시간 속도 평소 패턴
- **확인 필요**: 일러스트레이터에서 SVG 레이어 열기, 리포트·보드 인쇄(PDF), 건축물대장 지붕 구조 실제 키 조회
